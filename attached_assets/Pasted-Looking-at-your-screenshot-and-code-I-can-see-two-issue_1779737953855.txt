Root cause of the navbar overlap: Leaflet injects its own z-index on the map pane elements (typically z-index: 400). When you scroll, the map container climbs above a navbar that has no explicit z-index. Setting z-index: 0 on the map wrapper creates a new stacking context, capping all Leaflet internals within it — so they can't escape above the navbar.
Root cause of card clipping: maxHeight: 560 is a fixed pixel value. On shorter screens (laptops, 768px–900px height), this truncates cards mid-render. calc(100vh - 280px) sizes it relative to the actual viewport, giving it room to breathe on any screen.
